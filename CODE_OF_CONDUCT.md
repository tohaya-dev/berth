# Community conduct

Treat contributors and users with respect. Technical disagreement is welcome; harassment, threats, discriminatory abuse and disclosure of private information are not.

Use constructive, specific feedback. Respect boundaries and requests to stop unwanted contact. Do not post credentials, private documents or personal information in issues, pull requests or examples.

Maintainers may edit or remove harmful contributions and restrict participation when needed. Reports involving private information should use the repository's private security reporting channel when available; do not publish sensitive details in an issue. If no private channel is available, request a private contact method without including the details.

Maintainers should handle reports confidentially, consider context fairly and explain moderation decisions to the affected person when feasible.
