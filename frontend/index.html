Separate from the LLM's Top-K.RAG Chatで参照するドキュメント数（1〜100）。LLMのTop-Kとは別です。

A manual value takes precedence.空欄の場合は接続先から自動取得を試みます（LM Studio・Ollama対応）。手動指定があればそれを優先します。

    Export Settings (ZIP)設定をエクスポート（ZIP）
    
            
    
              Download the current workspace's settings, collection definitions, and guardrails as a ZIP.
    
              * Vector data is not included. Each collection must be re-published after import.    現在のワークスペースの設定・コレクション定義・ガードレールをZIPでダウンロードします。
    
              ※ベクターデータは含まれません。インポート後に各コレクションのPublishが必要です。    
            
    
            
            
    
              
    Select workspace to exportエクスポート対象ワークスペースを選択
    
              
    
                
                
              
    
              
    
            
    
            
            
            
            
    
              * Full export file size grows with the number of collections.※フルエクスポートはコレクション数に応じてファイルサイズが大きくなります
            
    
          
    
          
    
            
    Import ZIPZIPをインポート
    
            
    
              Select an exported ZIP file.
    
              * Settings-only ZIPs require re-publishing each collection after import.
    
              * Full-export ZIPs let you use RAG Chat immediately after import.    エクスポートしたZIPファイルを選択してください。
    
              ※設定のみZIPはインポート後に各コレクションのPublishが必要です。
    
              ※フルエクスポートZIPはインポート後すぐにRAG Chatが使えます。
